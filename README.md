# sd_telegram

[English](README_en.md) | [Русский](README.md)

Телеграм-бот для генерации изображений с помощью Stable Diffusion, созданный на основе Aiogram 3.

## Возможности

-   Генерация изображений с помощью Stable Diffusion
-   Поддержка пользовательских промптов, моделей, сэмплеров и других параметров
-   Предустановленные конфигурации для быстрой и легкой генерации изображений
-   Интеграция с VK и OK для обмена изображениями
-   Модульная и расширяемая архитектура

## Установка

1.  **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/soaska/sd_telegram.git
    cd sd_telegram
    ```

2.  **Создайте виртуальное окружение и установите зависимости:**

    ```bash
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    ```

3.  **Настройте переменные окружения:**

    Скопируйте файл `example.env` в `.env` и заполните необходимые значения.

    ```bash
    cp example.env .env
    ```

    -   `API_BOT_TOKEN`: Токен вашего телеграм-бота от [BotFather](https://t.me/BotFather).
    -   `ALLOWED_USERS`: JSON-массив идентификаторов пользователей, которым разрешено использовать бота. Оставьте пустым, чтобы разрешить всем пользователям.
    -   `SD_HOST`, `SD_PORT`, `SD_USERNAME`, `SD_PASSWORD`: Ваши учетные данные для API Stable Diffusion.
    -   `VK_TOKEN`, `VK_ALBUM_ID`, `OK_ACCESS_TOKEN`, `OK_APPLICATION_KEY`, `OK_APPLICATION_SECRET_KEY`, `OK_GROUP_ID`: Ваши учетные данные для API VK и OK.

## Использование

Для запуска бота используйте следующую команду:

```bash
python bot.py
```

## Команды

-   `/start`, `/help`: Показать стартовое сообщение и помощь.
-   `/gen`: Сгенерировать изображение с текущими настройками.
-   `/gen_custom`: Сгенерировать изображение с пользовательскими настройками.
-   `/skip`: Пропустить текущую генерацию изображения.
-   `/opt`: Показать меню опций.
-   `/sttngs`: Показать меню настроек.
-   `/scrpts`: Показать меню скриптов.
